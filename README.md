# Amazon Seller Lead Crawler

亚马逊商品/卖家信息自动采集工具，适合 B2B 客户开发、竞品分析、供应商调研。

## 功能

- 按关键词搜索亚马逊商品
- 自动采集：标题、价格、评分、评论数、品牌、卖家名
- 自动进入商品页提取描述中的邮箱
- 按评论数+评分排序（高价值线索排前面）
- 自动去重，已采集的不再重复
- 结果导出到"导出结果"文件夹

## 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. 修改关键词

打开 `keywords.txt`，每行或用逗号分隔多个关键词：

```
leather bag manufacturer,PU leather,genuine leather wallet
```

### 3. 运行

双击 `run.bat`，会自动打开浏览器开始采集。

### 4. 查看结果

采集完成后，结果在 `导出结果` 文件夹里，用 Excel 打开即可。

## 文件说明

| 文件 | 说明 |
|---|---|
| `keywords.txt` | 搜索关键词，改这里就行 |
| `run.bat` | 双击运行 |
| `历史记录.csv` | 自动生成，已采集记录 |
| `导出结果/` | 采集结果 Excel |

## 注意事项

- 第一次运行会弹出浏览器窗口，正常操作即可
- 采集速度约每秒 1 个商品，500 个约需 10 分钟
- 如果遇到验证码，手动在浏览器里完成即可
